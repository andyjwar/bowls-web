v23 — admin as the front page: tiles + inline score entry

No admin chrome, no dashboards. The admin home is the public home page's poster grid; opening a tile is the public league page with the same banner, division letters and week tiles — except the score in the middle of each fixture row is a box you can type in. Save sits on the bottom edge of the week tile.

A — admin home: the same poster grid

Exactly the front page, signed in. Each league tile shows how many results this week still need entering (the little counter sits where a score chip would). Cups follow in their own row, and the charcoal tiles hold everything else — players per team, and the form inbox.

B — score entry: the league page, editable

Identical anatomy to the public league page: banner with Monday/Wednesday tabs, division letters, and week tiles. Filters are the letters (by division) and the week pills (by week — defaults to this week). Played rows look exactly like the public site; unplayed rows swap the printed score for two boxes. One save button per week tile.
