A — one toolbar row

Dropdown and buttons share a single row: filter left, actions right, everything vertically centred. The visible label goes (the select's first option reads "All teams", plus a visually-hidden label for screen readers), so there's exactly one gap above the list.

C — attached control bar

Dropdown and buttons share one full-width card strip that sits flush on top of the list — its border merges with the tile below (like the team-record strip), zero gap. The controls read as part of the list they act on. Buttons lose their own borders and become cells of the strip.
