Club locations — five page treatments

Every option assumes: one entry per club green (~40), search + filters at top, tap opens Google/Apple Maps at the postcode. Map artwork here is illustrative; the build would use free OpenStreetMap static tiles (no API key) or plain link-outs.

Option A — mini-map card grid

A card per green with a real map thumbnail, pin, postcode, and a Directions link. Filter chips by league plus a search box. The most literal take on “small map screenshots”.

Option C — clean directory rows

No map imagery on the page at all: a fast, scannable directory. Monogram badge, club, which leagues play there, a postcode chip, and one-tap Google / Apple links. Lightest to build and quickest to use on a phone before a match.
